Stop reporting browser noise to Rollbar from `@seliseblocks/genesis-os/observability`. A new `checkIgnore` drops items that are not Blocks faults before they are sent: browser network failures (`Failed to fetch…`, `NetworkError when attempting to fetch resource.`, `Load failed`) and any `AbortError`, view-transition rejections, errors whose every stack frame is a browser extension, Monaco cancellations, stale Monaco workers after a deploy, `Object.hasOwn` on old browsers, bare `Event` rejections and `reCAPTCHA Timeout`. `createHttpFailureReporter` and the React Query reporter skip the same network failures, and still report every other transport failure and query bug. `applyTheme` now switches instantly while the page is hidden and handles the promises of the view transitions it starts, so theme changes no longer raise unhandled rejections. The IAM initiate call rejects a non-2xx answer with an `HttpError` carrying the status, so the AppSwitcher and the profile and console redirect hooks no longer report it. Classification fails open: if it throws, the item is reported. `classifyReportingNoise` and `isNetworkFailure` are exported for apps that report on their own.
